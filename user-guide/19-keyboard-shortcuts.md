# Keyboard shortcuts

*The complete shortcut reference.*

Press `⌘/` at any time to open the in-app shortcuts overlay.

## Requests

| Shortcut | Action |
|---|---|
| `⌘↵` | Send the current request |
| `⌘T` | Open a new empty request tab |
| `⌘W` | Close the active tab |
| `⌘S` | Save the request (in place if already saved, else the Save dialog) |

## Navigation

| Shortcut | Action |
|---|---|
| `⌘K` | Focus the Omnibox in command mode (the command palette) |
| `⌘P` | Focus the Omnibox in search mode (quick-open a saved request or history entry) |
| `⌘\` | Cycle Workbench focus: both panes → response → request → both |
| `⌘E` | Toggle the Environments panel (switch environment) |
| `⌘1` | Toggle the **Collections** panel |
| `⌘2` | Toggle the **History** panel |
| `⌘3` | Toggle the **Environments** panel |
| `⌘4` | Toggle the **Flows** panel |
| `⌘5` | Toggle the **Connections** panel |
| `⌘6` | Open **Settings** |
| `⌘/` | Toggle the keyboard-shortcuts overlay |

## Editor

| Shortcut | Action |
|---|---|
| `⌘F` | Find in the response |
| `Esc` | Close the shortcuts overlay, or close a floating (unpinned) panel |

## The Status strip hints

The bottom Status strip always shows a compact hint row: `⌘↵ Send`, `⌘K Commands`, `⌘P Open`, `⌘\ Focus`, `⌘E Env`, `⌘? Keys`.
